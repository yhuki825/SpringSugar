# Spring Sugar Website

このフォルダは、スプリングシュガーの企業サイトを静的HTMLとして納品するためのファイル一式です。

## 内容

- `index.html`: 完成版の静的HTMLです。CSSはHTML内にまとめているため、Cloudflare Pagesへそのままアップロードしやすい構成です。

## Cloudflare Pagesでの利用方法

Cloudflare Pagesで「Direct Upload」を選び、このフォルダ内の `index.html` を含むフォルダをアップロードしてください。ビルドコマンドは不要です。

## 編集時の注意

会社情報や文言は `index.html` 内の該当テキストを直接編集できます。コンタクトフォーム、代表者の顔写真枠は作成していません。
